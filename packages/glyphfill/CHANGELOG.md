# glyphfill

## 0.1.0

### Minor Changes

- 2a46593: First release.
  
  - `sweep`, `fill` and `weight` modes, a loading state (leave out `value`) and a `fillColor` option
  - `glyphfill()` for plain JavaScript, plus `glyphfill/react`, `glyphfill/vue` and `glyphfill/svelte`
  - Built-in hover and focus tooltip, `progressbar` semantics, reduced-motion support
  - Zero-specificity styles that work alongside Tailwind CSS, shadcn/ui, Chakra UI, MUI and styled-components
